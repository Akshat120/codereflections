Turn every hard problem into a lesson you keep.

CodeReflections is a practice journal for competitive programmers. Solve a Codeforces problem, then spend ten minutes writing down what unlocked it, so the next time a similar problem shows up, you recognise it instead of starting from zero.

See how it works ↓ View the source on GitHub
Why it exists

Solving more problems isn't the same as getting better. Two weeks after an "accepted", most of us couldn't solve the same problem again: the one idea that cracked it was never written down, so it faded, and the same mistakes come back.

The valuable part of a hard problem isn't the verdict, it's the insight. CodeReflections makes capturing it a habit, and brings it back before you forget it.

How it works
  1. 1

    Load

    Paste a Codeforces link or code like 1904A. Name, rating and tags are fetched for you.

  2. 2

    Solve

    Work on it on Codeforces while a stopwatch tracks the time you spend.

  3. 3

    Reflect

    Answer five short questions while it's fresh: the key idea, the trap, the pattern.

  4. 4

    Review

    Spaced repetition brings each lesson back after 1, 3, 7, 14… days. Progress shows where you get stuck.

The five questions
Key observation
The one idea that unlocked the problem.
What made me stuck
The trap, and how you got out. Tagged with a reason like "missed a constraint".
Pattern
The technique or family, e.g. "sliding window", "sort then greedy".
Future trigger
What to look for next time, so you recognise it faster.
Simplest implementation
The cleanest code that solves it.

Why I built it
I kept solving Codeforces problems and forgetting them. Rereading my old submissions told me what I wrote, not why it worked or where I went wrong. So I built the journal I wanted: one page per hard problem, written while the lesson is fresh, and a review queue that makes sure it sticks. Akshat Dhiman, creator
